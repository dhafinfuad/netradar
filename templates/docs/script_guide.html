Langkah 2: Cara Penggunaan

Instalasi Otomatis (Direkomendasikan)

Gunakan paket installer ini untuk mendaftarkan komputer secara permanen sebagai background service.

  1. Download file ipradar-agent-windows.zip.
  2. PENTING: Klik kanan pada file ZIP tersebut > Properties > centang kotak Unblock (Buka Blokir) di bagian bawah > OK.
    (Ini mencegah munculnya error "Windows cannot access the specified device...")
    💡 Jika masih muncul notifikasi error "unspecified path", silakan Restart komputer Anda lalu jalankan kembali Run_Installer.bat.
  3. Extract (Unzip) file ipradar-agent-windows.zip tersebut.
  4. Di dalam folder hasil ekstrak, klik 2x pada file Run_Installer.bat.
  5. Script akan otomatis membuka PowerShell dan meminta izin Administrator, pilih Yes.
  6. Masukkan IP belakang (opsional) dan NIP Pendek Pegawai dengan hak Akses Administrator Perangkat.
  7. Selesai! Komputer ini akan otomatis terdaftar di IP Radar setiap kali dinyalakan.
Penting: Jika Anda mengisi pertanyaan Target IP, script akan mengubah pengaturan jaringan (IP Statis) di komputer tersebut. Pastikan Anda mengizinkan saat diminta akses Administrator.
